Secure Cloud Storage System

File Splitting, Encryption and Secure Storage

About the Project

This project demonstrates how a file can be divided into smaller blocks, encrypted, and restored securely.

Project Objectives

  • Split a file into smaller blocks.
  • Encrypt blocks using Fernet encryption.
  • Store encrypted blocks securely.
  • Decrypt and combine blocks to restore the file.

Technologies Used

Python, Cryptography (Fernet), HTML, CSS and GitHub Pages.

Project Status

File splitting, encryption, decryption and restoration have been tested locally.

Cloud upload and download integration is the next phase.
